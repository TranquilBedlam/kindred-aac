# Kindred AAC

An offline-first, tablet-focused augmentative and alternative communication (AAC) and interactive learning application for children ages 4–8.

## Mission
Make independent communication available at all times, including during learning. Spoken language is never a prerequisite. Design for children using affordable and lower-powered devices.

## Development status
Early discovery and prototype phase. Not a validated clinical intervention or deployable tablet application.

## Ground rules
- MVC architecture with independent AAC, learning, and device-service boundaries.
- Test before modifying behavior; keep feature changes on branches and review before merging.
- Prioritize reliability, offline speech output, accessibility, privacy, and device performance.
- Review user-facing mockups before implementing layout changes.
- Distinguish automated tests from actual iPad/Android testing.
